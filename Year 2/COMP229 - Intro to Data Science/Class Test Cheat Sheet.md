
| Label                                      | Formula/Note                                                                                                                                                                                                                                                                         |

| Sample Var/SD                              | $Var = s^2 = \frac1{n-1}\sum_{i=1}^n(a_i-\bar a)^2$                                                                                                                                                                                                                                  |
| Outliers                                   | $[Q_1-1.5 \cdot \text{IQR},\;\; Q_3 + 1.5\cdot\text{IQR}]$                                                                                                                                                                                                                           |
| Skewness                                   | Right Skew/Positive Skew: More data is on the right/the right tail is longer<br>Left Skew/Negative Skew: More data is on the left/the left tail is longer<br>Mean does not necessarily have to match skew, but usually does.                                                         |
| Missing data                               | Dealing with missing data is done through: Omission, Imputation/Filling in (NEVER RANDOM/BLIND) or Analysis.                                                                                                                                                                         |
| Kolmogorov's axioms for probability spaces | Kolmogorov's axioms for Probability Spaces are:<br>1. Positivity: $P(A) \geq 0\; \forall\; A\in E$ <br>2. Something always happens: $P(\Omega)=1$<br>3. Additivity: The probability of the of 2 mutually exclusive events happening is the sum of their individual probabilities.    |
| Sum Rule                                   | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$                                                                                                                                                                                                                                                    |
| Product Rule                               | $P(A\cap B)=P(A\|B)P(B)$                                                                                                                                                                                                                                                             |
| Bayes-Price-Laplace                        | $P(A\|B)=\frac{P(B\|A)P(A)}{P(B)}$                                                                                                                                                                                                                                                   |
| Pairwise Independence                      | $\forall i,j\; \text{ such that } i\neq j,\; P(A_i\cap A_j)=P(A_i)P(A_j)$                                                                                                                                                                                                            |
| Mutual Independence                        | $P(\bigcap^k_{i=1}B_i) = \prod^k_{i=1}P(B_i)$                                                                                                                                                                                                                                        |
| Pairwise & Mutual                          | $Mutal \Rightarrow Pairwise \text{, but }Pairwise \nRightarrow Mutual$                                                                                                                                                                                                               |
| Encoding Types                             | - Label Encoding - Numerical value for each level - Only good for ordinals<br>- One-Hot Encoding - New variable of 1s and 0s for each level<br>- Dummy Encoding - One hot but with an omitted level (base level)<br>- Effect Encoding - Dummy encoding with base level value changed |
| F Score                                    | $F_\beta=(1+\beta^2)\cdot(\frac{precision\cdot recall}{\beta^2\cdot precision + recall})$ where $\beta$ is how much more important recall is than precision.                                                                                                                         |
| Simpson's paradox                          | When a trend in groups reverses upon combination of groups.                                                                                                                                                                                                                          |
| Expectation a variable                     | $E(X) = \sum^n_{i=1}p_iv_i$                                                                                                                                                                                                                                                          |
| Linearity of Expectation                   | $E(X+Y)=E(X)+E(Y),\;\;\;E(aX)=aE(X)$                                                                                                                                                                                                                                                 |
| Bernoulli Variable                         | $P(X=1)=p=1-P(X=0)=1-q$, where $p\in[0,1]\;\text{and}\;q=1-p$                                                                                                                                                                                                                        |
| Binomial Distribution                      | $f(k)=P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}$, $\binom{n}{k}=\frac{n!}{k!(n-k)!}$                                                                                                                                                                                                         |
| Poisson Distribution                       | $f(k)=P(X=k)=\frac{\lambda^ke^{-\lambda}}{k!}$ OR $P(X=k)=\frac{(rt)^ke^{-rt}}{k!}$                                                                                                                                                                                                  |
| Normal Distribution                        | $\phi_{\mu,\sigma^2}(x)=\frac1{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$                                                                                                                                                                                                   |
| The $\sigma-2\sigma-3\sigma$ rule          | - About 68% of observations are in the range $[\mu-\sigma, \mu+\sigma]$<br>- About 95% of observations are in the range $[\mu-2\sigma, \mu+2\sigma]$<br>- About 99.7% of observations are in the range $[\mu-3\sigma, \mu+3\sigma]$                                                  |
| Central Limit Theorem                      | $\lim_{n\to+\infty}\frac{\bar X-\mu}{\sigma/\sqrt n} = N(0,1)$, requires finite mean and variance                                                                                                                                                                                    |
| P Value                                    | $p = P(\text{Test Statistic or More Extreme} \| \text{null hypothesis})$                                                                                                                                                                                                             |
| Type 1 Error                               | Rejecting the null hypothesis when you shouldn't                                                                                                                                                                                                                                     |
| Type 2 Error                               | Not rejecting the null hypothesis when you should                                                                                                                                                                                                                                    |
| Important Z Values                         | Significance - Z Value<br>90% - $1.645\approx 1.7$<br>95% - $1.96\approx 2$<br>99% - $2.546\approx 2.6$                                                                                                                                                                              |
| Curse of Dimensionality                    | Uniform spreads congregate in unintuitive areas of the dimension space. The formula for a ball which half the volume of a unit ball in $n$ dimensions is $r_n={\frac12}^\frac1n$.                                                                                                    |
| Students Distribution                      | Generalisation of the normal distribution which has tails controlled by the parameter $v$ (degrees of freedom). $v\to\infty$ means it becomes $N(0,1)$. $E(X)=0$ for all $v>1$.                                                                                                      |
| Cauchy Distribution                        | PDF: $f_{(m,\gamma)}(x)=\frac{1}{\pi\gamma}\Bigg[\frac{\gamma^2}{(x-m)^2+\gamma^2}\Bigg]$<br>Has infinite mean and variance. Ratio between two normal variables.                                                                                                                     |
| Pareto Distribution                        | PDF: $f_X(x)=\begin{cases}\frac{\alpha x^{\alpha}_m}{x^{\alpha+1}}, & x\geq x_m \\0, & x < x_m\end{cases}$<br>Power law distribution. Mean can be finite or infinite depending on $\alpha$.                                                                                          |
| Equivalence Relation Axioms                | - Reflexivity<br>- Symmetry <br>- Transitivity                                                                                                                                                                                                                                       |
| Dot Product                                | $\vec u \cdot \vec v = \sum_{i=0}^n u_iv_i = \|\vec u\| \cdot \|\vec v\| \cdot \cos\alpha$<br><br>$\alpha = \arccos\frac{\vec u\cdot\vec v}{\|\vec u\|\cdot\|\vec v\|},\;\; \|\vec u \cdot \vec v\| \leq \|\vec u\| \cdot \|\vec v\|$                                                |
| Normalisation                              | To scale the data so that all real values are in the range $[0,1]$                                                                                                                                                                                                                   |
| Standardisation                            | To scale the data so that the mean is 0 and the standard deviation is 1.                                                                                                                                                                                                             |
| Min-Max Scaling                            | $f_n(x)=\left(\frac{x-p}{q-p}\right)^n$                                                                                                                                                                                                                                              |
| Sample Covariance                          | $q_{xy}=\frac{1}{n-1}\sum^n_{i=1}(x_i-\bar x)(y_i-\bar y)$                                                                                                                                                                                                                           |
| Correlation                                | $r_{xy} =\frac{cov(X,Y)}{\sigma_X\sigma_Y}= \frac{\sum^n_{i=1}(x_i-\bar x)(y_i - \bar y)}{\sqrt{\sum^n_{i=1}(x_i-\bar x)^2\sum^n_{i=1}(y_i - \bar y)^2}}$                                                                                                                            |
| Linear Dependence                          | $y=ax+b,\;\;r_{xy} = sign(a)$                                                                                                                                                                                                                                                        |
| Linear Regression                          | $a=\frac{\sum^n_{i=1}(x_i-\bar x)(y_i-\bar y)}{\sum^n_{i=1}(x_i-\bar x)^2},\;\; b = \bar y - ax$                                                                                                                                                                                     |
| Root Mean Squared Error                    | $RMSE=\sqrt{\frac1n\sum(y_i-\hat y_i)^2}$                                                                                                                                                                                                                                            |
| Mean Absolute Percentage Error             | $MAPE=\frac1n \sum\frac{\|y_i-\hat y_i\|}{\|y_i\|}$                                                                                                                                                                                                                                  |
| $R^2$                                      | $R^2=1-\frac{SS_{res}}{SS_{tot}}=1-\frac{\sum(y_i-\hat y)^2}{\sum(y_i-\bar y)^2}$                                                                                                                                                                                                    |
